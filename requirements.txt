# AIP-Speech: one environment for every stage and all five models.
# Python 3.10-3.12 (the paper's runs used 3.10). Install with `python setup.py`.
# The paper's runs used separate environments, with transformers>=4.49 and unpinned torch
# (Qwen/Gemma baselines), 4.48.2 and peft 0.11.1 (Phi-4), and GitHub main (KWS steering).
#
# PyTorch is a prerequisite and not listed here: first install the CUDA build of
# torch >= 2.4 with its matching torchvision for your GPU from the PyTorch index
# (https://pytorch.org/get-started/locally/), e.g. the release the paper's Phi-4 runs used:
#   pip install torch==2.5.1 torchvision==0.20.1 --index-url https://download.pytorch.org/whl/cu124
# (from PyPI, Windows gets a CPU-only torch). setup.py checks this and installs the
# rest without letting pip replace that torch. torchaudio is not needed.
#
# Non-obvious pins:
# - transformers, peft, accelerate, bitsandbytes, huggingface_hub, timm: the newest
#   releases when the paper's Qwen2.5-Omni, Qwen2-Audio and Gemma 3n runs were set up
#   (late June 2026, installed unpinned). transformers 5 keeps the 8-bit models' other
#   layers in the checkpoint's bfloat16 (4.x: float16) and needs peft >= 0.19 and
#   timm >= 1.0.23 (Gemma 3n's vision tower). Phi-4's remote code targets 4.48.2;
#   07_run_inference.py patches it so that its outputs match 4.48.2.
# - tokenizers 0.22.2: the newest release transformers 5.12.1 accepts (<= 0.23.0).
# - datasets 3.5.1: Stage 2 streams fsicoli/common_voice_17_0 through its loading
#   script; datasets >= 4.0 no longer runs scripts and 3.6.0 rejects this one's extra
#   transcript columns.
# - backoff: imported by Phi-4's remote code. soxr: librosa's resampler.
# - numpy, scipy, pandas, matplotlib: the newest releases that support Python 3.10.
